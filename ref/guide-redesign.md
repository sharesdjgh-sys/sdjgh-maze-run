# 놀이 방법·공통 팝업 디자인 통일

## 화면 구성

- 예전 보라색 목록과 큰 카드형 안내를 정원 안내서로 바꿨습니다.
- 타이틀·선택·승리 화면과 같은 숲색, 크림색, 금빛 테두리, 버튼과 키캡을 사용합니다.
- 등교·하교, 두 사람의 조작, 아이템, 함정을 네 구역으로 나눴습니다.
- 학교→내 집 흐름을 기존 3D 아이콘으로 보여 주고, 현재 선택된 공부캐 이름과 그림을 조작 안내에 표시합니다.
- 아이템 6종에 나에게/상대에게 대상을 표시하고, 숫자는 설정값에서 읽어 짧게 설명합니다.
- 함정은 현재 규칙에 맞는 거미줄·얼음 바닥 2종을 안내합니다.
- 키캡은 실제 WASD·방향키 배치로, 2P 아이템은 숫자패드 1·2와 노트북 .·/를 함께 안내합니다.

## 공통 디자인

- `src/styles/guide.css`에 안내서 스타일과 공통 카드·키캡·버튼의 정원 테마를 정리했습니다.
- 일시정지·오류 팝업에도 같은 크림색 표면, 금빛 테두리와 녹색 주요 버튼을 적용했습니다.
- 기존 그림과 글꼴을 재사용했고 새로운 외부 의존성을 추가하지 않았습니다.

## 이동과 작은 화면

- 안내서의 Enter·숫자패드 Enter와 '친구 고르러 가기' 버튼은 캐릭터 선택으로 이어집니다.
- Esc/H는 타이틀로 돌아가고, M 또는 소리 버튼으로 음소거를 전환합니다.
- 작은 화면은 내용 영역만 스크롤하고 제목과 이동 버튼은 고정합니다.
- 소리를 전환해도 읽던 스크롤 위치가 유지됩니다.
- 이동·난이도·아이템 효과·승리 조건은 변경하지 않았습니다.

## 검증

- 관련 UI·조작 테스트 22개 통과.
- 브라우저에서 네 구역, 아이템 6종, 함정 2종, 선택된 공부캐 이름을 확인했습니다.
- 1440×900, 1366×768, 1024×768, 800×450, 390×844에서 가로 넘침과 하단 버튼 잘림을 점검했습니다.
- Enter·버튼으로 친구 선택, Esc/H로 타이틀, 소리 전환 및 게임 시작·일시정지 흐름을 확인했습니다.
- USB 단일 HTML을 file://로 열어 아이콘 포함 여부와 안내→친구 선택 이동을 확인했습니다.
- 일반·USB 빌드 및 PWA 캐시 생성 완료. USB 파일 약 6.35MB.
- git diff --check 통과.
