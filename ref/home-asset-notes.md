# 캐릭터별 집 에셋

16종 캐릭터의 동물 특징과 학습 성향(청각·운동·촉각·시각 / 혼자·함께 / 유연·계획)을 반영한 전용 집입니다. 부드러운 클레이 3D 스타일과 투명 배경을 공통으로 사용합니다.

- 생성 방식: 내장 `image_gen` 도구, 캐릭터당 개별 생성 1회
- 최종 프롬프트: `ref/home-asset-prompts.json`
- 생성 원본: `ref/home-originals/<캐릭터 id>.png`
- 게임용 에셋: `src/assets/homes/<캐릭터 id>.webp` (256 × 256, 알파 유지)
- 집 이름·디자인 설명: `src/data/homes.js`
- 재변환 및 미리보기 생성: `npm run homes`
- 비교용 미리보기: `ref/character-homes-preview.html` (파일을 브라우저로 직접 열 수 있음)

선택한 `player.character`로 집 그림을 고릅니다. 1P·2P 색상 테두리와 이름표, 등교 후 빛과 맥박 효과는 유지합니다. 원본의 여백을 정리한 뒤 같은 크기의 투명 캔버스로 맞추며, 게임에서는 칸의 0.72배로 표시합니다. 불러오기 실패 시 기존 공통 집 아이콘을 표시합니다.

미리보기는 캐릭터와 집의 큰 비교 이미지, 32px·48px 축소 이미지, 학습 감각별 필터, 정원·어두운 배경·투명 확인 모드를 제공합니다. 원본 링크는 각 생성 PNG로 연결됩니다.

## 승리 화면

단상을 가리던 버튼 모양의 1P/2P 캐릭터 이름표는 제거했습니다. 승자 정보는 상단에 플레이어 번호와 캐릭터 이름을 합쳐 표시합니다(예: 2P 루트 승리!, 2P 루트 최종 우승!). `ref/victory-home-preview.html`은 2P 루트 승리 배치를 브라우저로 열어 볼 수 있는 로컬 미리보기입니다.

단판 승리·시리즈 각 판 승리·최종 우승 화면에서 집은 오른쪽 뒤 정원에, 우승 캐릭터는 왼쪽 앞의 작은 단상에 표시합니다. 집과 캐릭터의 바닥을 분리해 깊이를 만들고, 단상 너비에 비례한 발 위치를 사용해 화면 높이가 달라도 캐릭터가 단상에서 떠 보이지 않게 합니다. 무대 너비는 화면 높이에도 맞춰 제한하며, 기쁨 동작은 발을 축으로 좌우로 기울이는 방식입니다. 트로피·점수·다음 판 버튼을 유지하고 무승부는 기존 두 캐릭터 연출을 사용합니다. `src/ui/result.js`에서 우승 캐릭터의 집 에셋을 선택하고 `src/styles/garden-menus.css`의 `victory-homecoming` 스타일로 배치합니다. 수정된 배치 캡처는 `ref/victory-home-layout-desktop.png`·`ref/victory-home-layout-laptop.png`·`ref/victory-home-layout-mobile.png`에 로컬 저장합니다.
