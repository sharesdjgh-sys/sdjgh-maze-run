# 제공 영상으로 만든 승리 애니메이션

## 입력과 변환

사용자가 제공한 `ref/VictoryVideos/*.mp4` 16개를 사용합니다. 원본 영상과 Unity `.meta` 파일은 수정하지 않습니다. 캐릭터 ID와 영상 이름의 대응은 `src/data/victory.js`에서 관리합니다.

`npm run victories`는 ffmpeg로 8초 영상을 초당 12프레임으로 읽고, 자주색 배경을 제거한 256 × 256 투명 애니메이션 WebP를 `src/assets/victory/<id>.webp`에 저장합니다. ffmpeg가 PATH에 있어야 합니다. 캐릭터 하나만 변환하려면 `npm run victories -- deer`처럼 ID를 지정합니다.

- 프레임별 배경 키 색을 모서리에서 읽어 압축 색상 차이를 반영합니다.
- 부분 투명 경계에서 자주색을 빼고, 경계 매트를 얇게 정리해 색 번짐을 줄입니다.
- 각 프레임에서 가장 큰 연결 영역인 캐릭터 몸체를 찾습니다. 떨어진 먼지·반짝이 효과가 자르기 영역을 넓혀 캐릭터를 작게 만드는 일을 막습니다.
- 모든 프레임에 같은 자르기 영역을 사용해 동작 도중 크기나 기준 위치가 흔들리지 않게 합니다.
- 반복 재생하며, 프레임별 지연을 83/84ms로 나눠 전체 8초 길이를 유지합니다.
- 변환 결과 기록: `ref/victory-animation-build.json`.

## 게임에서의 사용

승리 화면은 우승 캐릭터에 해당하는 WebP를 사용합니다. 무승부에서는 두 캐릭터의 애니메이션을 표시합니다. 기존 전용 집, 작은 단상과 제목·점수·버튼 배치를 유지합니다. 공중에 떠 있던 별도 트로피는 제거하고 단상의 금빛 별 장식으로 우승을 표현합니다. 영상 자체의 춤과 손짓이 보이도록 별도 CSS 흔들림을 중첩하지 않습니다.

`picture`의 미디어 조건으로 운영체제의 **동작 줄이기** 설정을 따릅니다. 이 설정에서는 기존 정지 캐릭터 그림을 사용합니다. 화면에 표시된 캐릭터의 애니메이션만 요청하고, 시작 화면에서 16종 애니메이션을 모두 미리 불러오지는 않습니다. PWA 캐시와 단일 HTML 빌드에는 게임 에셋으로 포함됩니다.

## 미리보기

`npm run victories:preview`는 실제 `resultScreen`을 Vite SSR로 불러와 `ref/victory-home-preview.html`을 다시 만듭니다. 수작업으로 복제한 마크업 대신 게임의 최신 문구·배치를 사용합니다. 로컬 HTML을 직접 열어 볼 수 있습니다.

오른쪽 위 **미리보기 설정**에서 16종 캐릭터, 1P/2P, 단판 승리/최종 우승, 정지 그림을 선택할 수 있습니다. 영상 원본의 자주색 배경은 미리보기에 나타나지 않습니다. 화면에 있는 게임 버튼은 배치 확인용입니다.
