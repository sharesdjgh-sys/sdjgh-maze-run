[ 미로찾기 게임 — 최종 제출 요약 ]
작성자: 임성민
작성일: 2026. 10. 28.
대상 공모전: 창의 게임

═══ 문제 정의 ═══
한 줄 소개: 한 컴퓨터에서 두 친구가 키보드를 나눠 쓰며, 랜덤 미로 양 끝에서 출발해 가운데 보물을 먼저 차지하기 위해 트릭 아이템으로 겨루는 귀여운 웹 대결 게임
해결하려는 문제: 학교 행사에서 설치나 별도 기기 없이 친구들이 함께 즐길 수 있는 재미있는 게임이 부족합니다. 단순한 미로 경주는 쉽게 질리고 실력 차이가 크면 한쪽이 일찍 흥미를 잃기 때문에, 매번 다른 미로와 역전 요소를 통해 누구나 끝까지 긴장감 있게 참여할 수 있는 2인 대결 게임이 필요합니다.
배경 및 필요성: 학교 행사에서는 여러 친구가 한 자리에 모여 짧은 시간 안에 규칙을 이해하고 바로 즐길 수 있는 콘텐츠가 필요합니다. 웹 기반이라 브라우저에서 링크만 열면 바로 실행되고, 한 컴퓨터에서 키보드를 나눠 쓰므로 옆에서 응원하고 놀리는 분위기를 만들 수 있습니다. 랜덤 미로와 난이도 조절로 처음 하는 친구도 고수도 즐길 수 있고, 귀여운 캐릭터와 이펙트는 구경하는 친구들의 참여와 환호를 이끌어냅니다. Claude Code로 개발하고 Vercel로 배포해 수정과 공유가 빠릅니다.

기능 개요:
두 명의 플레이어가 귀여운 캐릭터를 선택한 뒤, 같은 랜덤 생성 미로의 양쪽 끝에서 동시에 출발해 가운데 보물을 먼저 획득하면 승리하는 단판승 게임입니다. 한 명은 W, A, S, D로, 다른 한 명은 방향키로 이동합니다. 미로 곳곳에 랜덤 아이템이 배치되며 최대 2개까지 보관할 수 있고, 전용 키(Q/E, 숫자패드 1/2)로 원하는 타이밍에 사용합니다. 아이템은 내 속도 증가, 상대 속도 감소, 상대 3초 멈춤, 상대 조작키 반대, 상대 주변 어둡게 하기의 다섯 가지이며, 사용 시 얼음, 화면 암전, 화면 흔들림 같은 이펙트가 나타납니다. 미로 크기로 난이도를 조절하고, 게임 종료 후 재도전 버튼으로 바로 다시 시작할 수 있습니다. 플레이 시간을 확인한 뒤 3판 2선승제로 확장할 수 있습니다.

═══ 이해관계자 분석 ═══
▸ 게임을 직접 플레이하는 학생 (주요 사용자, 13~18세 중·고등학생)
  현재 불편함: 학교 행사에서 친구들과 함께 즐길 만한 게임이 마땅치 않고, 기존 게임은 설치나 계정 가입이 필요해 바로 시작하기 어렵습니다. 대부분 혼자 하는 게임이라 한 컴퓨터에서 친구와 마주 앉아 겨루는 재미를 느끼기 힘듭니다.
  SW 사용 목적: 한 컴퓨터에서 키보드를 나눠 쓰며 친구와 미로 속 보물을 먼저 차지하는 대결을 즐기려 합니다. 랜덤 아이템과 귀여운 캐릭터로 매번 새로운 재미와 역전의 짜릿함을 느끼고 싶어 합니다.
  SW와의 관계: 게임의 직접 사용자로서 캐릭터를 고르고 아이템 전략을 쓰며 대결하는 핵심 플레이어입니다.

▸ 구경하는 친구들(관객) (보조 사용자, 13~18세 중·고등학생)
  현재 불편함: 게임 순서를 기다리는 동안 지켜볼 거리가 마땅치 않아 지루합니다. 화면에서 무슨 일이 벌어지는지 알기 어려운 게임은 응원하거나 함께 즐기기 힘듭니다.
  SW 사용 목적: 친구들의 대결을 옆에서 보며 응원하고 놀리면서 행사 분위기를 즐기려 합니다. 얼음, 어둠 같은 이펙트로 상황을 한눈에 이해하고 함께 환호하고 싶어 합니다.
  SW와의 관계: 직접 플레이하지 않아도 이펙트와 대결 장면을 보며 분위기를 만들고, 다음 도전자로 참여할 수 있는 잠재 사용자입니다.

▸ 학교 행사 담당 교사/학생회 (운영자, 20~50대 교사 및 10대 후반 학생회 임원)
  현재 불편함: 행사에 쓸 프로그램을 준비할 때 별도 설치나 복잡한 설정이 필요하면 부담이 큽니다. 행사장 인터넷이 불안하거나 학생들이 금방 질려 하면 진행이 매끄럽지 않습니다.
  SW 사용 목적: 링크 하나로 브라우저에서 바로 실행하고, 규칙이 간단해 설명 없이도 학생들이 참여하는 게임을 운영하려 합니다. 한 판이 짧고 재도전이 쉬워 많은 학생이 돌아가며 즐기길 바랍니다.
  SW와의 관계: 행사 부스나 프로그램으로 게임을 운영하며 설치 없는 웹 접속과 빠른 회전율의 혜택을 얻는 운영 주체입니다.

═══ 기능 설계 ═══
[ 기능 1: 랜덤 미로 생성 및 난이도 조절 ]
기능 설명: 게임을 시작할 때마다 새로운 미로가 랜덤으로 만들어집니다. 쉬움(10x10)부터 어려움(30x30)까지 칸 수를 조절해 난이도를 선택할 수 있어, 처음 하는 친구도 고수도 모두 즐길 수 있습니다. 미로 바깥쪽 양 끝에서 출발해 가운데 보물을 향해 나아갑니다.

  [ 처리 단계 ]
  단계 1 (사용자 입력) — 게임 시작 화면에서 두 친구가 쉬움, 보통, 어려움 중 원하는 난이도 버튼을 눌러 골라요.
    입력 데이터: 난이도 선택 (쉬움 10x10 / 보통 20x20 / 어려움 30x30)
  단계 2 (조건 분기) — 고른 난이도에 따라 미로의 칸 수를 정해요. 쉬움이면 칸 수를 적게, 어려움이면 칸 수를 많게 설정해요. 난이도를 고르지 않고 시작하면 기본값인 쉬움으로 시작해요.
    입력 데이터: 선택한 난이도 값
    출력/결과: 미로 칸 수 (가로 x 세로)
  단계 3 (시스템 처리) — 게임이 시작될 때마다 컴퓨터가 벽을 무작위로 세우고 허물면서 새로운 미로를 만들어요. 가운데 보물까지 반드시 길이 이어지도록 만들고, 양쪽 바깥 끝에 두 친구의 출발 위치를 정해요.
    입력 데이터: 미로 칸 수, 무작위 값
    출력/결과: 새로 만들어진 미로 지도, 출발 위치 2곳, 보물 위치
  단계 4 (결과 출력) — 화면에 새 미로가 나타나고, 양쪽 끝에 두 친구의 귀여운 캐릭터가, 가운데에는 보물이 보여요. 이제 각자 키보드로 캐릭터를 움직여 보물을 향해 출발해요.
    출력/결과: 미로 화면, 캐릭터 2명, 가운데 보물, 시작 카운트다운
  단계 5 (오류 처리) — 미로 만들기에 실패하거나 가운데로 가는 길이 막혀 있으면 그 미로를 버리고 자동으로 새 미로를 다시 만들어요. 그래도 안 되면 안내 문구와 함께 다시 시작 버튼을 보여줘요.
    입력 데이터: 미로 생성 실패 신호
    출력/결과: 미로를 다시 만드는 중이에요 안내 메시지, 다시 시작 버튼

[ 기능 2: 2인 로컬 대결 및 귀여운 캐릭터 선택 ]
기능 설명: 한 컴퓨터에서 키보드를 나눠 쓰는 2인 대결입니다. 한 명은 W/A/S/D, 다른 한 명은 방향키로 움직이고, 시작 전에 동물이나 음식 같은 귀여운 캐릭터를 각자 고릅니다. 두 사람은 동일한 미로의 양쪽 끝에서 출발해 가운데 보물을 먼저 차지하는 쪽이 이깁니다.

  [ 처리 단계 ]
  단계 1 (사용자 입력) — 게임을 시작하기 전에 두 친구가 각자 마음에 드는 귀여운 캐릭터(동물, 음식 등)를 고르고, 미로 난이도(쉬움/보통/어려움)도 선택해요.
    입력 데이터: 플레이어 1·2의 캐릭터 선택, 난이도 선택
  단계 2 (시스템 처리) — 게임이 선택한 난이도에 맞는 크기로 새로운 미로를 무작위로 만들어요. 두 캐릭터는 미로의 양쪽 끝에, 보물은 가운데에 놓고 아이템도 곳곳에 랜덤으로 뿌려둬요.
    입력 데이터: 난이도(미로 칸 수), 선택한 캐릭터 정보
    출력/결과: 새로 만들어진 랜덤 미로, 캐릭터 시작 위치, 가운데 보물, 랜덤 아이템 배치
  단계 3 (사용자 입력) — 한 친구는 W/A/S/D 키로, 다른 친구는 방향키로 자기 캐릭터를 움직여요. 아이템을 먹으면 최대 2개까지 보관하고, 전용 키(Q·E 또는 숫자패드 1·2)로 원할 때 사용해요.
    입력 데이터: 이동 키 입력(W/A/S/D, 방향키), 아이템 사용 키 입력
  단계 4 (조건 분기) — 캐릭터가 움직일 때마다 벽에 막혔는지, 아이템을 먹었는지, 보물에 도착했는지 확인해요. 벽이면 못 가고, 보물에 먼저 닿은 사람이 있으면 그 사람이 승리해요.
    입력 데이터: 캐릭터의 현재 위치, 벽·아이템·보물 위치
    출력/결과: 이동 가능 여부, 아이템 획득 처리, 승리 판정
  단계 5 (결과 출력) — 보물을 먼저 차지한 친구의 승리 화면을 보여주고, 바로 다시 할 수 있는 재도전 버튼을 띄워요.
    출력/결과: 승리 캐릭터 축하 화면, 재도전 버튼

[ 기능 3: 랜덤 트릭 아이템 5종 ]
기능 설명: 미로 곳곳에 랜덤으로 배치된 아이템을 획득합니다. 종류는 내 속도 증가, 상대 속도 감소, 상대 3초 멈춤, 상대 조작키 반대로, 상대 주변 어둡게 하기 총 5가지입니다. 역전의 재미를 만들어 누가 이길지 끝까지 알 수 없게 합니다.

  [ 처리 단계 ]
  단계 1 (시스템 처리) — 게임이 시작되면 컴퓨터가 새로 만든 미로 곳곳에 아이템 상자를 무작위로 놓아요. 상자 안에 어떤 아이템이 들어 있는지는 먹기 전까지 아무도 몰라요.
    입력 데이터: 미로 크기(난이도), 아이템 상자 개수
    출력/결과: 아이템 상자가 곳곳에 놓인 미로 화면
  단계 2 (사용자 입력) — 두 친구가 각자 키보드로 캐릭터를 움직여 아이템 상자가 있는 칸으로 걸어가요.
    입력 데이터: 이동 키 (W/A/S/D 또는 방향키)
  단계 3 (조건 분기) — 캐릭터가 상자를 먹었을 때 이미 아이템을 2개 들고 있는지 확인해요. 2개보다 적으면 새 아이템을 가방에 넣고, 가득 차 있으면 아이템을 얻지 못해요.
    입력 데이터: 현재 보관 중인 아이템 개수
    출력/결과: 아이템 획득 효과음 또는 '가방이 가득 찼어요' 안내 문구
  단계 4 (사용자 입력) — 원하는 타이밍에 아이템 전용 키를 눌러 가방 속 아이템을 사용해요. 지금 쓸지, 아껴뒀다가 상대와 마주칠 때 쓸지 선택하는 심리전이 생겨요.
    입력 데이터: 아이템 사용 키 (Q/E 또는 숫자패드 1/2)
  단계 5 (결과 출력) — 사용한 아이템 효과가 화면에 바로 나타나요. 내 속도는 빨라지고, 상대는 느려지거나 3초간 얼음이 되거나 조작키가 반대로 바뀌거나 화면이 어두워져요.
    출력/결과: 속도 변화, 얼음 효과, 화면 흔들림, 화면 어두워짐 등 이펙트

[ 기능 4: 아이템 보관(최대 2개) 및 전용 사용 버튼 ]
기능 설명: 획득한 아이템은 최대 2개까지 보관했다가 원하는 타이밍에 사용합니다. 아이템 전용 키가 이동키와 분리되어 있어 헷갈리지 않습니다(예: WASD 플레이어는 Q/E, 방향키 플레이어는 숫자패드 1/2). '지금 쓸까, 아껴둘까' 하는 심리전이 핵심 재미입니다.

  [ 처리 단계 ]
  단계 1 (시스템 처리) — 캐릭터가 미로 속 아이템 상자에 닿으면, 게임이 5가지 아이템(내 속도 증가, 상대 속도 감소, 상대 3초 멈춤, 조작키 반대로, 주변 어둡게 하기) 중 하나를 랜덤으로 뽑아줘요.
    입력 데이터: 캐릭터가 아이템 상자에 닿은 위치
    출력/결과: 랜덤으로 뽑힌 아이템 1개
  단계 2 (조건 분기) — 내 아이템 칸이 비어 있는지 확인해요. 2칸 중 빈 칸이 있으면 그 칸에 아이템을 저장하고, 2칸이 모두 차 있으면 새 아이템은 받을 수 없어요.
    입력 데이터: 현재 보관 중인 아이템 개수(0~2개)
    출력/결과: 저장 가능 / 저장 불가 판단 결과
  단계 3 (오류 처리) — 아이템 칸이 가득 찼는데 상자를 먹으려 하면 "가방이 가득 찼어요!"라고 알려주고, 아이템은 저장하지 않아요. 아이템이 없는 칸의 사용 키를 눌러도 아무 일도 일어나지 않아요.
    입력 데이터: 아이템 2개 보관 중 상자 접촉, 또는 빈 칸의 사용 키 입력
    출력/결과: "가방이 가득 찼어요!" 안내 문구
  단계 4 (사용자 입력) — 플레이어가 원하는 타이밍에 아이템 전용 키를 눌러요. WASD 플레이어는 Q/E, 방향키 플레이어는 숫자패드 1/2를 눌러서 아이템 1번 또는 2번을 사용해요.
    입력 데이터: 아이템 사용 키 (Q/E 또는 숫자패드 1/2)
  단계 5 (결과 출력) — 선택한 아이템의 효과가 바로 화면에 나타나요. 멈춤은 얼음 효과, 어둡게 하기는 화면이 확 어두워지는 효과, 조작키 반대는 화면 흔들림 효과로 보여주고, 사용한 아이템은 칸에서 사라져요.
    출력/결과: 아이템 효과 이펙트(얼음, 어두워짐, 화면 흔들림 등)와 갱신된 아이템 칸 표시

[ 기능 5: 아이템 시각 이펙트 ]
기능 설명: 아이템을 쓰면 효과가 한눈에 보이도록 이펙트가 나타납니다. 멈춤은 얼음 효과, 어둡게 하기는 화면이 확 어두워지고 내 주변만 보이는 효과, 조작키 반대는 화면 흔들림 효과로 표현합니다. 당한 사람뿐 아니라 구경하는 친구들도 함께 환호할 수 있습니다.

  [ 처리 단계 ]
  단계 1 (사용자 입력) — 게임 중에 플레이어가 자기 아이템 버튼(Q·E 또는 숫자패드 1·2)을 눌러서 보관해둔 아이템을 사용해요.
    입력 데이터: 아이템 사용 키 입력 (Q, E 또는 숫자패드 1, 2)
  단계 2 (조건 분기) — 누른 버튼에 아이템이 들어 있는지 확인해요. 아이템이 없으면 아무 일도 일어나지 않고, 있으면 그 아이템의 종류가 무엇인지 알아내요.
    입력 데이터: 보관 중인 아이템 목록, 아이템 종류
  단계 3 (시스템 처리) — 아이템 종류에 맞는 효과를 상대에게 적용해요. 멈춤은 3초간 움직이지 못하게, 조작키 반대는 방향키가 거꾸로 되게, 어둡게 하기는 시야를 좁게 만들어요. 사용한 아이템은 보관함에서 지워요.
    입력 데이터: 사용한 아이템 종류, 효과를 받는 플레이어
  단계 4 (결과 출력) — 효과에 맞는 이펙트를 화면에 보여줘요. 멈춤은 캐릭터가 얼음으로 변하고, 어둡게 하기는 화면이 확 어두워지며 내 주변만 보이고, 조작키 반대는 화면이 흔들려요. 구경하는 친구들도 한눈에 알 수 있어요.
    출력/결과: 얼음 효과, 화면 어두워짐 효과, 화면 흔들림 효과
  단계 5 (시스템 처리) — 정해진 효과 시간이 끝나면 이펙트를 자동으로 없애고, 캐릭터 조작과 화면을 원래 상태로 되돌려요.
    입력 데이터: 효과 지속 시간
    출력/결과: 이펙트가 사라지고 정상 화면으로 복귀

[ 기능 6: 단판승 게임 진행 및 재도전 ]
기능 설명: 가운데 보물을 먼저 획득한 사람이 바로 승리하는 단판승 방식입니다. 결과 화면에서 승자를 보여주고 '재도전' 버튼으로 바로 다시 시작할 수 있습니다. 플레이 시간을 측정해본 뒤 3판 2선승제로 확장할 수 있도록 설계합니다. 웹 브라우저에서 바로 실행되며 Vercel로 배포해 링크만으로 접속할 수 있습니다.

  [ 처리 단계 ]
  단계 1 (사용자 입력) — 두 친구가 캐릭터와 난이도를 고른 뒤 '시작' 버튼을 눌러 게임을 시작해요. 한 명은 W, A, S, D 키로, 다른 한 명은 방향키로 움직여요.
    입력 데이터: 캐릭터 선택, 난이도(미로 크기), 시작 버튼 클릭, 이동 키 입력
  단계 2 (시스템 처리) — 게임이 시작될 때마다 새로운 랜덤 미로를 만들어요. 두 친구는 미로 양쪽 끝에서 출발하고, 보물은 가운데에 놓이고 아이템도 여기저기 무작위로 배치돼요.
    입력 데이터: 선택한 난이도, 선택한 캐릭터
    출력/결과: 랜덤 미로, 양쪽 끝 출발 위치, 가운데 보물, 곳곳의 아이템
  단계 3 (조건 분기) — 게임이 진행되는 동안 누군가 가운데 보물에 먼저 닿았는지 계속 확인해요. 먼저 닿은 사람이 있으면 바로 승리가 결정되고, 아직 없으면 게임을 계속해요.
    입력 데이터: 두 캐릭터의 현재 위치, 보물 위치
    출력/결과: 승자 결정 또는 게임 계속 진행
  단계 4 (결과 출력) — 게임이 끝나면 승리한 친구와 캐릭터를 화면에 크게 보여줘요. 플레이한 시간도 함께 보여줘서 3판 2선승제로 늘려도 될지 판단할 수 있어요.
    출력/결과: 승자 표시 화면, 플레이 시간, 재도전 버튼
  단계 5 (사용자 입력) — 친구들이 '재도전' 버튼을 누르면 새로운 랜덤 미로로 바로 다시 게임을 시작해요. 웹 링크 하나로 접속하니 따로 설치할 필요도 없어요.
    입력 데이터: 재도전 버튼 클릭
    출력/결과: 새 미로로 게임 재시작

[배경 및 필요성]
학교 행사에서는 짧은 시간에 누구나 규칙을 바로 이해하고 함께 웃으며 즐길 수 있는 콘텐츠가 필요합니다. 기존 온라인 게임은 설치나 계정 가입이 필요하고 혼자 하는 경우가 많아 행사 현장에서 친구들이 한자리에 모여 즐기기에는 불편합니다. 또한 실력 차이가 크면 한쪽이 쉽게 흥미를 잃기 때문에, 초보자도 이길 기회가 있는 역전 요소가 필요합니다. 이에 설치 없이 브라우저에서 바로 실행되고, 한 대의 컴퓨터에서 두 친구가 키보드를 나눠 쓰며 옆에서 응원하고 놀리는 재미까지 살린 2인 대결 웹게임 '귀염뽀짝 미로 레이스'를 기획했습니다.

[해결 방안]
- 게임 개요: 두 명의 플레이어가 동일한 미로의 양쪽 끝에서 동시에 출발하여 가운데에 있는 보물을 먼저 획득하면 승리하는 대결 게임입니다.
- 플레이 방식: 한 컴퓨터에서 키보드를 나눠 사용합니다. 1P는 W, A, S, D로 이동하고 Q, E로 아이템 1번과 2번을 사용합니다. 2P는 방향키로 이동하고 숫자패드 1, 2로 아이템을 사용합니다.
- 랜덤 미로: 게임을 시작할 때마다 새로운 미로가 자동 생성되어 반복해도 질리지 않습니다. 난이도는 미로 칸 수(예: 쉬움 10x10, 어려움 30x30)로 조절합니다.
- 역전 요소인 랜덤 아이템: 미로 곳곳에 랜덤 아이템을 배치하고, 아이템을 보관했다가 원하는 타이밍에 사용하는 심리전을 만듭니다. 아이템은 최대 2개까지 보관할 수 있어 '지금 쓸지, 마주칠 때 아껴둘지'를 고민하게 됩니다.
- 귀여운 캐릭터: 플레이어가 동물이나 음식 같은 귀여운 캐릭터 중 하나를 선택하여 플레이합니다.
- 개발 및 배포: Claude Code로 웹 UI를 개발하고 Vercel로 배포하여 링크만으로 학교 컴퓨터 브라우저에서 바로 실행합니다.

[주요 기능]
1. 시작 화면 및 캐릭터 선택: 게임 이름과 함께 귀여운 캐릭터를 고르고, 난이도를 선택하는 화면입니다.
2. 랜덤 미로 생성: 매 판 새로운 미로를 생성하며 두 플레이어가 동일한 미로를 공유합니다. 양쪽 끝에서 출발하고 중앙에 보물이 있습니다.
3. 2인 키보드 분할 조작: 이동 키와 아이템 전용 키를 분리하여 조작이 헷갈리지 않게 합니다.
4. 랜덤 아이템 5종 (최대 2개 보관, 전용 버튼으로 사용)
  - 내 속도 증가
  - 상대 속도 감소
  - 상대 3초 멈춤 (얼음 이펙트)
  - 상대 조작키 반대로 (화면 흔들림 이펙트)
  - 상대 주변 어둡게 하기 (내 주변만 보이도록 화면이 어두워지는 이펙트)
  ※ 시작 지점으로 되돌리는 아이템은 친구 사이의 흥을 깰 수 있어 제외했습니다.
5. 사용 이펙트: 아이템을 쓰면 상대가 당한 것을 구경하는 친구들도 한눈에 알 수 있는 시각 효과를 보여줍니다.
6. 승리 판정 및 재도전: 보물을 먼저 획득하면 단판승으로 승리가 결정되며, 재도전 버튼으로 바로 다시 시작할 수 있습니다. 플레이 시간을 측정해 보고 이후 3판 2선승제로 확장할 수 있습니다.

[개발 계획]
1단계: 랜덤 미로 생성과 캐릭터 이동
2단계: 아이템 생성, 보관, 사용 및 효과와 이펙트
3단계: 시작 화면, 캐릭터 선택, 난이도 설정
4단계: Vercel 배포, 행사장 환경 사전 접속 테스트, 친구들 피드백 반영
※ Claude Code에 지금까지 정한 규칙(2인 대결, 랜덤 미로, 아이템 5종, 보관 2개, 단판승)을 글로 정리해 전달합니다.

[기대 효과]
- 설치나 가입 없이 링크 하나로 접속하여 행사 현장에서 바로 즐길 수 있습니다.
- 랜덤 미로와 랜덤 아이템 덕분에 누가 이길지 끝까지 알 수 없어, 초보자도 역전할 수 있고 반복 플레이 가치가 높습니다.
- 한 화면에서 함께 즐기며 응원하고 환호하는 과정에서 친구들 간 소통과 유대감이 커집니다.
- 귀여운 캐릭터와 이펙트로 첫인상이 좋아 처음 보는 사람도 '해보고 싶다'고 느끼며, 발표 시 짧은 영상으로 매력을 전달할 수 있습니다.
- 단판승으로 시작해 3판 2선승 등으로 확장할 수 있어 향후 기능 추가에도 유연합니다.
- 행사장 인터넷 환경이 불안할 수 있으므로 사전 접속 테스트로 안정적인 운영을 준비합니다.
